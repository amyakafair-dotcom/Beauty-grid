# ١٠٠ ستايل فني للفيديو

2026-10-31

## كيف تُصنع

كل الـ100 ستايل تُصنع بالكود: Python (مكتبات PIL وmoviepy وmanim) وffmpeg، أو HTML وCanvas وSVG وthree.js. التسليم ملف MP4 أو صفحة متحركة.

- **يحتاج صورك:** الستايلات المعلّمة بـ ★ تحتاج صوراً أو فيديو خام منك.
- **تقريبي:** الستايلات المعلّمة بـ ○ تحاكي المظهر، ولا تطابق الرسم اليدوي.
- **غير ممكن بدون كونكتر:** فيديو واقعي مُولّد بالذكاء الاصطناعي، أشخاص حقيقيون يتحركون، صوت بشري مسجّل.

للطلب: رقم الستايل، النص أو الصور، المدة، والمقاس (9:16 أو 1:1 أو 16:9).
